WORD CARDS — версия для iPhone
================================

Содержимое:
- index.html — интерфейс
- style.css — оформление
- app.js — карточки, рандом, статистика и словарь
- manifest.json + service-worker.js — установка на домашний экран и офлайн-кэш
- icon-192.png / icon-512.png — иконки

ВАЖНО:
На iPhone PWA нельзя полноценно установить, открыв index.html как локальный файл.
Файлы нужно разместить на HTTPS-хостинге (например, GitHub Pages), затем открыть адрес в Safari.

Установка на iPhone:
1. Размести все файлы из этой папки на HTTPS-хостинге.
2. Открой сайт в Safari на iPhone.
3. Нажми «Поделиться» → «На экран Домой» → «Добавить».
4. Запусти Word Cards с новой иконки.

Перенос слов из Windows:
1. На компьютере открой папку с word_cards.py.
2. Найди words.json рядом с ним. Если файла ещё нет, запусти Windows-приложение и добавь/сохрани слова — файл появится.
3. Передай words.json на iPhone (например, через iCloud Drive или «Файлы»).
4. В Word Cards открой «Мои слова» → «Импорт words.json» и выбери файл.
5. При вопросе выбери замену текущего словаря или добавление к нему.

Хранение:
Слова хранятся в localStorage браузера на этом устройстве. Удаление данных сайта или браузера может удалить локальный словарь, поэтому периодически используй «Экспорт слов» как резервную копию.
Синхронизации между ПК и iPhone в этой версии нет; импорт/экспорт предусмотрен для будущего переноса.
